MSW Overwatch 3.8.3 — desktop and web release

Patch release since 3.8.2. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## FBA Order Checker
- Entering a box number lists only the items already counted into that box

## Label Station
- Custom labels can print on 3x2 stock as well as 3x3

## Upgrade from 3.8.2
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.8.3, download it, then prompt to install now or later. Web/PWA users get 3.8.3 on the next deploy/refresh.
