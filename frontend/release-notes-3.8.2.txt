MSW Overwatch 3.8.2 — desktop and web release

Patch release since 3.8.1. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## FBA Order Checker
- The owner of a shipment can choose who it is shared with
- Box and SKU filters no longer freeze those fields
- Box numbers stay in sequence, and gaps are reported on the accounting file
- A skipped box number warning appears above the box field

## Shipment list
- Stored filters sit apart from All and Mine
- Saved filters are easier to tell apart

## NFA and SMW
- Zero carton dimensions get suggested values

## Scheduler
- A second scheduler no longer inserts a stuck Import Mode daily job

## Upgrade from 3.8.1
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.8.2, download it, then prompt to install now or later. Web/PWA users get 3.8.2 on the next deploy/refresh.
