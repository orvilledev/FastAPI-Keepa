MSW Overwatch 3.8.5 — desktop and web release

Patch release since 3.8.4. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## Label Station
- Signing out on one station no longer signs the same account out on every other computer
- A dead session returns to the login page instead of showing a scan as "Not in catalog"
- "Not in catalog" is shown only when the item is really missing

## Floor stations
- Label1–Label8 and Pack1–Pack6 use the same station access as Warehouse1

## Upgrade from 3.8.4
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.8.5, download it, then prompt to install now or later. Web/PWA users get 3.8.5 on the next deploy/refresh.
