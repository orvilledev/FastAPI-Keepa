MSW Overwatch 3.6.5 — desktop and web release

Label Station queue fix since 3.6.4. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## Label Station
- Queue mode prints only what was scanned: three scans print three labels
- A scan is added to the queue once, so the last scan is no longer printed again at the end

## Desktop
- Label Center stays on the web. The desktop app opens Label Station instead.

## Upgrade from 3.6.4
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.6.5, download it, then prompt to install now or later. Web/PWA users get 3.6.5 on the next deploy/refresh.
