MSW Overwatch 3.9.1 — desktop and web release

Patch release since 3.9.0. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## FBA Order Checker
- Choose FNSKU label design in-place when printing, without opening Label Station

## App cleanup
- Projects is removed (unused personal work-log tool)
- SMW Shipment Analyzer is removed from BC Tools

## Upgrade from 3.9.0
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.9.1, download it, then prompt to install now or later. Web/PWA users get 3.9.1 on the next deploy/refresh.
