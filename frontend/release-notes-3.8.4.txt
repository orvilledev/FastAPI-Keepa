MSW Overwatch 3.8.4 — desktop and web release

Patch release since 3.8.3. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## Sign in
- The email field offers previously used sign-in addresses so they do not have to be typed again
- An address can be removed from the list on this device

## Upgrade from 3.8.3
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.8.4, download it, then prompt to install now or later. Web/PWA users get 3.8.4 on the next deploy/refresh.
