MSW Overwatch 3.8.7 — desktop and web release

Patch release since 3.8.6. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## Dimensioner
- Every signed-in account can open Dimensioner, including warehouse stations
- hello@warehouserepublic.com remains blocked

## Upgrade from 3.8.6
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.8.7, download it, then prompt to install now or later. Web/PWA users get 3.8.7 on the next deploy/refresh.
