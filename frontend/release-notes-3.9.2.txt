MSW Overwatch 3.9.2 — desktop and web release

Patch release since 3.9.1. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## FBA Order Checker
- Visual refresh: folders panel and selected-row colors updated; related accents matched
- Larger table headers, Folders label, and top toolbar text
- Unarchive completed shipments back to active (shared workers included)
- Live search as you type
- Overage status still shows when filtered by box (including after search)

## Dimensioner
- Select all and delete selected (bulk)
- Deletes go to Trash with Restore / Delete forever
- Trash auto-emptied after 15 days

## Upgrade from 3.9.1
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.9.2, download it, then prompt to install now or later. Web/PWA users get 3.9.2 on the next deploy/refresh.
