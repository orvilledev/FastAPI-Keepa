MSW Overwatch 3.5.0 — desktop and web release

Feature release since 3.4.3. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## Tools
- New allowlisted **FBA Box Contents** tool converts FBA Carton Detail reports into typed Excel workbooks

## Shipment Manager
- **NFA shipment checklist** with progress tracking and who completed each step
- Superadmins can edit per-vendor checklists and who completed a step
- NFA checklist template applied to SMW Smartwool
- Shipment creators can set workflow status

## Docs
- About and FAQ synced with current Menu and Tools features

## Upgrade from 3.4.3
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.5.0, download it, then prompt to install now or later. Web/PWA users get 3.5.0 on the next deploy/refresh.
