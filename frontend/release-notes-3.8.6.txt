MSW Overwatch 3.8.6 — desktop and web release

Patch release since 3.8.5. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## Maintenance
- Selected emails can keep using Overwatch while maintenance mode is on

## Label Center
- A 1.5 by 1 inch No Knife sticker is available
- The artwork is scaled down 5 percent so it stays inside the page

## FBA Order Checker
- Anyone a shipment is shared with can archive it into a chosen folder
- A shared shipment can be archived before counting is finished
- Stored shipment row actions fit on the list so they show when the page opens

## BC Tools
- The NS Tool reports monthly sales and returns totals that match the reference workbook

## Upgrade from 3.8.5
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.8.6, download it, then prompt to install now or later. Web/PWA users get 3.8.6 on the next deploy/refresh.
