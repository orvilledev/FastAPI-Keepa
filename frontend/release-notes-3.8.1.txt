MSW Overwatch 3.8.1 — desktop and web release

Patch release since 3.8.0. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## FBA Order Checker
- Shipments keep an editable Name
- The accounting download uses the shipment Name from the upload
- FNSKU labels print in box order
- FNSKU labels can be printed before a shipment is fully counted
- Printing includes only the FNSKU labels that match the box or SKU filter

## My Space
- Custom links can switch between cards, list, and compact views

## Upgrade from 3.8.0
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.8.1, download it, then prompt to install now or later. Web/PWA users get 3.8.1 on the next deploy/refresh.
