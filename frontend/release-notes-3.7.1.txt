MSW Overwatch 3.7.1 — desktop and web release

Patch release since 3.7.0. Installers and auto-update use GitHub Releases. The desktop app checks for updates on its own (startup, every 4 hours, and after sleep) and installs a downloaded update the next time you quit. You can still use **Check for Updates** / **Install now** to apply immediately.

## Label Center
- Label preview draws again in the desktop app
- Print sends the label to the selected Zebra instead of stopping with "i.toHex is not a function"

## Upgrade from 3.7.0
Windows desktop: open MSW Overwatch and wait a few seconds — it should find 3.7.1, download it, then prompt to install now or later. Web/PWA users get 3.7.1 on the next deploy/refresh.
